# ai-image-classification
Image Classification using Teachable Machine

Project Overview

This project demonstrates a simple image classification model built using Google Teachable Machine and TensorFlow/Keras. The model is trained to classify images into two categories: Cat and Dog.

Steps

1. Opened Google Teachable Machine.
2. Created two classes:
    * Cat
    * Dog
3. Added two training images for each class.
4. Trained the model using Teachable Machine.
5. Exported the trained model in TensorFlow/Keras format.
6. Opened Google Colab and loaded the provided Python prediction script.
7. Uploaded the exported model files:
    * keras_model.h5
    * labels.txt
8. Ran the code to load the model and test an input image.
9. The model predicted the image class successfully, as shown in the attached output screenshot.

Files Included

* predict.py
* keras_model.h5
* labels.txt
* Sample test image

Tools Used
